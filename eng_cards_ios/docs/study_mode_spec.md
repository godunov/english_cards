# ТЗ: Режим обучения "Перевод -> Слово"

## 1. Общее описание

Режим обучения предназначен для запоминания английских слов методом флеш-карточек.

**Направление обучения:** русский перевод → английское слово

Пользователь видит русский перевод и должен вспомнить английское слово. После этого он может проверить себя, посмотрев ответ.

**Контекст запуска:**
- Режим запускается из экрана категорий (`CategoryListView`)
- Работает с карточками из одной выбранной категории изученности

---

## 2. Источник данных

### Загрузка слов
- Слова загружаются из `ProgressService` по выбранной категории
- Используется метод `progressService.getWordIds(in: category)`
- Полные данные слов загружаются из `DataService`

### Порядок слов
- При старте сессии слова **перемешиваются** в случайном порядке
- После прохождения всех слов список **перемешивается заново** и обучение продолжается с начала

### Структура данных слова (Word)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Int | Уникальный идентификатор |
| `word` | String | Английское слово |
| `translation` | String | Русский перевод |
| `transcription` | String | Транскрипция (IPA) |
| `imagePath` | String | Путь к изображению |
| `audioPath` | String | Путь к аудио файлу |

## 3. Структура экрана обучения (StudySessionView)

### Хедер
```
[Прогресс]          [Таймер]          [Кнопка аудио]
   1/25             5 сек                  🔊
```

- **Прогресс:** формат "текущий/всего" (например, "1/25")
- **Таймер:** отображает время в секундах с момента показа вопроса
- **Кнопка аудио:** воспроизводит произношение текущего слова

### Заголовок навигации
- Название текущей категории (например, "Не могу вспомнить")

---

## 4. Структура карточки (FlashCardView)

### Вопрос (лицевая сторона)
Показывается при `isShowingAnswer = false`

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│             [Перевод]               │
│            "привет"                 │
│                                     │
│                                     │
│   "Нажмите, чтобы увидеть ответ"   │
└─────────────────────────────────────┘
```

**Элементы:**
- Русский перевод слова (крупный шрифт, по центру)
- Подсказка внизу карточки

### Ответ (обратная сторона)
Показывается при `isShowingAnswer = true`

```
┌─────────────────────────────────────┐
│          [Изображение]              │
│             📷                       │
│                                     │
│           [Слово]                   │
│           "hello"                   │
│                                     │
│        [Транскрипция]               │
│          /həˈləʊ/                   │
│                                     │
│          [Перевод]                  │
│          "привет"                   │
│                                     │
│  "Нажмите для следующей карточки"  │
└─────────────────────────────────────┘
```

**Элементы:**
- Изображение (если есть, иначе placeholder)
- Английское слово (крупный шрифт, синий цвет)
- Транскрипция (если есть)
- Русский перевод
- Подсказка внизу карточки

## 5. Взаимодействие с карточкой

### Жесты
| Действие | Состояние карточки | Результат |
|----------|-------------------|-----------|
| Тап на карточку | Вопрос | Показ ответа + воспроизведение аудио |
| Тап на карточку | Ответ | Переход к следующей карточке |
| Тап на кнопку аудио | Любое | Воспроизведение аудио |

### Автоматическое воспроизведение аудио
- Аудио воспроизводится **автоматически** при показе ответа
- Можно повторно воспроизвести через кнопку в хедере

---

## 6. Таймер

### Поведение
| Событие | Действие таймера |
|---------|-----------------|
| Показ вопроса | Запускается с 0 |
| Показ ответа | Останавливается |
| Переход к следующей карточке | Сбрасывается и запускается |

### Отображение
- Формат: "{N} сек" (например, "5 сек")
- Шрифт: monospacedDigit для стабильной ширины

## 7. Категории изученности

### Список категорий
| Категория | Короткое название | Иконка | Цвет |
|-----------|------------------|--------|------|
| Не могу вспомнить | Не помню | xmark.circle | Красный |
| Могу вспомнить с трудом | С трудом | questionmark.circle | Оранжевый |
| Могу вспомнить | Помню | checkmark.circle | Желтый |
| Легко вспоминаю | Легко | star.circle | Зеленый |
| Автоматически помню | Авто | bolt.circle | Синий |

### Кнопки категорий
```
┌─────────────────────────────────────────────────────────┐
│              "Переместить в категорию:"                 │
│  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐          │
│  │  ✕  │  │  ?  │  │  ✓  │  │  ★  │  │  ⚡ │          │
│  │Не   │  │С    │  │Помню│  │Легко│  │Авто │          │
│  │помню│  │труд.│  │     │  │     │  │     │          │
│  └─────┘  └─────┘  └─────┘  └─────┘  └─────┘          │
└─────────────────────────────────────────────────────────┘
```

### Состояния кнопок
| Состояние | Описание |
|-----------|----------|
| **Неактивно** | Когда показывается вопрос. Кнопки приглушены (opacity 0.4), клики игнорируются |
| **Активно** | Когда показывается ответ. Кнопки кликабельны |
| **Выбрано** | Текущая категория слова. Кнопка выделена фоном и рамкой |

### Поведение при выборе категории
1. Выбор возможен **только при показе ответа**
2. При выборе категории:
   - Слово перемещается в выбранную категорию
   - Соответствующая кнопка становится активной (выделяется)
   - Слово **остается видимым** на экране
3. Переход к следующему слову происходит **только по клику на карточку**
4. Если слово перемещено в другую категорию:
   - Оно удаляется из текущего списка
   - Но продолжает отображаться до клика на карточку

## 8. Навигация и прогресс

### Прогресс
- Формат: "текущий/всего" (например, "5/25")
- Обновляется при переходе к следующей карточке

### Цикличность
- После прохождения последней карточки:
  - Список слов перемешивается заново
  - Индекс сбрасывается на 0
  - Обучение продолжается бесконечно

### Удаление слов из списка
- Если слово перемещено в другую категорию, оно удаляется из текущего списка
- Счетчик прогресса обновляется соответственно

## 11. Диаграмма состояний

```
┌─────────────┐                    ┌─────────────┐
│   ВОПРОС    │──── тап ──────────▶│   ОТВЕТ     │
│             │                    │             │
│ - Перевод   │                    │ - Картинка  │
│ - Таймер ▶  │                    │ - Слово     │
│ - Категории │◀── тап ───────────│ - Таймер ■  │
│   неактивны │   (→след.слово)   │ - Категории │
└─────────────┘                    │   активны   │
       ▲                           └─────────────┘
       │                                  │
       │                                  │
       └──────── выбор категории ─────────┘
                 (слово остается)
```

---

## 12. Ключевые особенности поведения

1. **Нет автоматического перехода** — следующее слово показывается только по клику пользователя
2. **Слово остается видимым** после выбора категории до клика на карточку
3. **Таймер измеряет время раздумья** — от показа вопроса до показа ответа
4. **Бесконечное обучение** — после прохождения всех слов цикл повторяется
5. **Категории доступны только при ответе** — защита от случайных нажатий
